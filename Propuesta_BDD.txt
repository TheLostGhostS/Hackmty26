Descripción de cada bloque:

| Bloque                                     | Descripción                                                                                                                                                                    |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **1. Identidad y perfil**                  | Contiene la información básica y relativamente estable del usuario que permite identificarlo y darle contexto para personalizar la experiencia.                                |
| **2. Realidad financiera**                 | Representa la situación financiera real y verificable del usuario: sus productos financieros, movimientos, ingresos y obligaciones.                                            |
| **3. Inteligencia financiera derivada**    | Contiene métricas, patrones y análisis calculados a partir de la información financiera del usuario, como tendencias de gasto, capacidad de ahorro o utilización de crédito.   |
| **4. Objetivos e intenciones del usuario** | Representa lo que el usuario quiere conseguir o cambiar financieramente, como ahorrar, invertir, comprar algo, reducir gastos o pagar una deuda.                               |
| **5. Preferencias de experiencia**         | Contiene las preferencias del usuario sobre cómo quiere interactuar con el sistema, como nivel de detalle, formato o estilo de comunicación.                                   |
| **6. Contexto de la interacción**          | Representa lo que está ocurriendo en la interacción actual, como la pantalla, producto seleccionado, período, filtros, acción reciente o tarea que está realizando el usuario. |


Tipos de datos:

| Tipo                          | Descripción                                                                                                                                                                                |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **[HECHO]**                   | Información real, verificable y observable sobre el usuario, sus productos o sus operaciones. Representa lo que **es o ha ocurrido**.                                                      |
| **[DATO DERIVADO]**           | Información obtenida mediante cálculos, agrupaciones, comparaciones o análisis realizados sobre uno o varios hechos. Representa lo que **podemos concluir o medir a partir de los datos**. |
| **[OBJETIVO / INTENCIÓN]**    | Información que representa lo que el usuario **quiere conseguir, cambiar o hacer**, incluyendo metas, planes, preferencias financieras e intenciones expresadas.                           |
| **[CONTEXTO DE INTERACCIÓN]** | Información temporal relacionada con la **situación actual de la interacción**, como la pantalla, producto seleccionado, filtros, acción reciente o tarea que está realizando el usuario.  |
